# Universal Media Archiver

Desktop application starter for downloading public media from supported platforms using yt-dlp.

Features:
- YouTube, Instagram, TikTok and other yt-dlp supported extractors
- Highest available quality download
- Video and gallery/media posts when supported by extractor
- Metadata TXT export
- Thumbnail download when available

Install:

pip install -r requirements.txt

Run:

python app/main.py

Use only for content you have permission to download.
